# Data Dictionary

| Field | Type | Meaning |
|---|---|---|
| month | date | Month of reporting |
| revenue | numeric | Monthly revenue |
| profit | numeric | Monthly profit |
| active_customers | integer | Active customers during the month |
| orders | integer | Number of orders |
| marketing_spend | numeric | Monthly marketing spend |
| sla_breach_rate | numeric | Share of service activity breaching SLA |
| profit_margin | numeric | Profit divided by revenue |
| aov | numeric | Average order value |
| roas | numeric | Revenue divided by marketing spend |

**Grain:** one row per month.
