# Dashboard showcase

The portfolio includes dashboard specifications and visual previews for the six case studies.

## Featured views

- Sales & Revenue: executive sales, category, regional and channel performance
- Customer Churn: retention, revenue-at-risk and customer segments
- E-commerce Funnel: acquisition, device conversion and funnel drop-off
- Marketing: spend, revenue, ROAS, CAC and campaign efficiency
- Operations: productivity, absence, SLA and quality
- Executive BI: revenue, profit, margin, AOV, ROAS and operational KPIs

The main README surfaces a dashboard preview so visitors can see the reporting style before opening a project.
