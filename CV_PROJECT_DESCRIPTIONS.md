# CV-ready project descriptions

## Sales & Revenue Analytics
Built a reproducible retail sales analysis using Python, SQL and Excel/BI-style reporting; analysed revenue, profit margin, product, regional and channel performance and translated findings into business recommendations.

## Customer Churn & Retention
Analysed a synthetic subscription customer base using Python and SQL to measure churn, active MRR and revenue at risk, with segmentation by plan and customer tenure.

## E-commerce Funnel Analysis
Analysed 12,000 synthetic web sessions with SQL and Python to measure product-view, cart, checkout and purchase conversion, identifying performance differences by traffic source and device.

## Marketing Campaign Performance
Built a campaign-performance analysis covering spend, impressions, clicks, leads, conversions, revenue, ROAS and CAC, with channel-level comparisons and campaign-level efficiency analysis.

## Operations & Workforce Analytics
Analysed workforce productivity using Python and SQL, comparing hours, absence, output, SLA breaches and quality scores across teams and shifts.

## Executive BI Dashboard
Designed an executive KPI model combining revenue, profit, margin, orders, AOV, active customers, marketing spend, ROAS and SLA performance for trend and management reporting.
