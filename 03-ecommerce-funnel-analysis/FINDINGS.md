# Findings Framework

Run the generator and analysis to reproduce the funnel. Review overall stage-to-stage conversion, then compare acquisition sources and devices.

## Questions for a BI review

- Where is the largest absolute and percentage drop-off?
- Which traffic sources convert most efficiently?
- Does mobile behave differently from desktop?
- Which stage represents the largest recoverable opportunity?

## Business actions to test

- Diagnose the largest funnel drop with session-level UX data.
- Compare landing pages and campaign intent for weak sources.
- Test mobile checkout friction separately from desktop.
- Estimate incremental revenue from realistic conversion improvements.

## Limitation

The dataset is synthetic and does not represent actual web traffic.
