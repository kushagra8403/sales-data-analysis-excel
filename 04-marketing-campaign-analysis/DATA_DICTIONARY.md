# Data Dictionary

| Field | Type | Meaning |
|---|---|---|
| campaign_id | string | Unique campaign identifier |
| channel | category | Marketing channel |
| spend | numeric | Campaign spend |
| impressions | integer | Ad/email impressions |
| clicks | integer | Clicks generated |
| leads | integer | Leads generated |
| conversions | integer | Converted leads/customers |
| revenue | numeric | Revenue attributed to campaign |
| roas | numeric | Revenue divided by spend |

**Grain:** one row per campaign.
