# Data Dictionary

| Column | Type | Description |
|---|---|---|
| order_id | integer | Unique order identifier |
| order_date | date | Date the order was placed |
| region | text | UK sales region |
| category | text | Product category |
| product | text | Product name |
| customer_id | text | Synthetic customer identifier |
| channel | text | Online, Store or Corporate |
| quantity | integer | Units purchased |
| unit_price | decimal | Price per unit before discount |
| discount | decimal | Discount rate applied to the order |
| sales | decimal | Net sales value after discount |
| profit | decimal | Synthetic profit value |
