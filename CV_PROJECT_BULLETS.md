# CV-ready project descriptions

Use only the projects you can confidently explain in an interview.

### Sales & Revenue Analytics
- Built an end-to-end retail sales analysis using Python, SQL and Excel to evaluate revenue, profit margin, product, regional and channel performance.
- Created reproducible KPI analysis and a Power BI dashboard specification covering trend, product and regional performance.

### Customer Churn & Retention
- Analysed a synthetic customer base with Python and SQL to measure churn, active MRR and revenue at risk across plans and tenure segments.
- Designed retention-focused KPI views to identify customer segments for further investigation and testing.

### E-commerce Funnel Analysis
- Analysed 12,000 synthetic web sessions to quantify product-view, cart, checkout and purchase conversion using SQL and pandas.
- Compared conversion and revenue by traffic source and device and translated funnel drop-offs into dashboard requirements.

### Marketing Campaign Performance
- Analysed campaign spend, leads, conversions, revenue, ROAS and CAC across marketing channels using Python and SQL.
- Designed a BI view combining efficiency and scale so channel decisions are not based on clicks or ROAS alone.

### Operations & Workforce Analytics
- Built an operational scorecard covering hours, absence, output, SLA breaches and quality across teams and shifts.
- Used SQL and pandas to compare workforce performance and define dashboard views for staffing and service-level investigation.

### Executive BI Dashboard
- Built a 24-month executive KPI model covering revenue, profit, margin, customers, orders, AOV, marketing efficiency and SLA performance.
- Defined an executive dashboard structure that connects commercial, customer, marketing and operational signals in one reporting view.

## Short portfolio summary

Built six end-to-end analytics projects using SQL, Python/pandas, Excel and Power BI-style dashboard design, covering sales, churn, e-commerce funnels, marketing, workforce operations and executive KPI reporting.
